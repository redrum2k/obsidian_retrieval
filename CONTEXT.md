# Obsidian retrieval and processing

The vault contains authoritative study sources and notes. Retrieval supplies evidence; scheduled processing proposes and carries out explicitly approved study-note work.

## Language

**Original source**:
An input document preserved as evidence for study work, including Raw/glossary inputs and eligible study documents outside Raw.

**Source revision**:
A particular content version of an original source. Processing one revision does not complete later changes to that source.

**Derived note**:
A Markdown study note produced from identified original sources and stored in a designated output folder.

**Intake check**:
A review of changed and outstanding study inputs, prioritizing Raw/glossary material before eligible study documents outside Raw. It does not grant permission to write notes.

**Actionable material**:
New or changed study material requiring processing under the existing workflow, with sufficient evidence to propose concrete note changes.

**Pending work**:
Observed source material whose required processing has not completed, including work awaiting review, approval, or recovery from failure.
_Avoid_: Unindexed material

**Processing proposal**:
A concrete, reviewable set of intended note creations, note/link updates, and processing-log changes tied to specific source revisions.

**Approval**:
The owner's explicit consent to the exact revision of a processing proposal. Silence, delivery of a notification, and scheduled execution are not approval.

**Processing completion**:
The state reached when all approved note/link changes are verified and their source hashes, output mappings, and completion status are recorded in the processing log.
_Avoid_: Indexed, extracted, notified

**Processing log**:
The existing workflow record of source revisions, their derived outputs, and processing status.
_Avoid_: Operational log
